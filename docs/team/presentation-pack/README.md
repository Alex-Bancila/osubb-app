# OSUBB team presentation pack

These are byte-for-byte copies of the four self-contained documents originally
published as private Claude artifacts. They were recovered from the local
workspace on August 27, 2026 and placed in the repository so access no longer
depends on a subscription or an external artifact link.

## The four documents

1. [OSUBB Build Journal](./osubb-build-journal.html) — the story of what was
   built, in chronological order, with the reason behind each decision.
   Snapshot date: **August 24, 2026**.
2. [Road to October](./road-to-october.html) — the implementation sequence,
   issue workflow, sprint map, and work that remained at that point. Snapshot
   date: **August 24, 2026**.
3. [OSUBB Team Kickoff](./osubb-team-kickoff.html) — a meeting handout covering
   the product, working backend, technology stack, team rules, and first week.
   Snapshot date: **August 24, 2026**.
4. [Setting Up Your Laptop](./setting-up-your-laptop.html) — a from-zero Windows
   setup walkthrough, including Docker, GitHub, Supabase, the database, and the
   frontend. Snapshot date: **August 25, 2026**.

Each HTML file contains its own CSS and has no external runtime assets. No
server or internet connection is needed: double-click a file to open it in
Edge, Chrome, or another browser.

## Snapshot versus current truth

The recovered documents are intentionally preserved as the last published
versions. Some counts, issue numbers, and next-step recommendations became
outdated as implementation continued after their snapshot dates.

## Preservation rule

Future presentation documents must be committed to the repository before they
are published anywhere else. A hosted artifact may be a convenient viewer, but
it must never be the only copy.
