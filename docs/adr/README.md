# Architecture Decision Records

Index of accepted ADRs. Each file uses one header template — `Status · Date · Deciders · Supersedes · Superseded by · Related` — followed by Context, Decision, and Consequences. ADR-0007 and ADR-0008 are authoritative for the Task Tracker and Calendar models respectively; see `CLAUDE.md` and `CONTEXT.md` for how these fit the rest of the repo's docs.
