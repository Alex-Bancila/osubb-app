Responsibles change no setting.
6. **Capabilities: one server RPC.** `public.my_capabilities()` returns one row of booleans from live state (rank + Group Roles); `app/src/lib/capabilities.ts` becomes a typed reader of it; guards stay cosmetic, RLS stays the authority; the level map dies.

## Cross-cutting rules for every backend task

- **Locks:** target `groups` row `for update`; parents (and, for archive, descendants) `for no key update`; several `groups` rows always in ascending `id`; target `group_members` row `for update`; the actor's own rows `for share` inside `require_*`; a `profiles` row `for share` before writing a roster row naming it. **Never `for share` on a `groups` row** — the Wave 1 reason (the mirror's implicit `for no key update`) dies with the mirror, but a stronger one replaces it: `require_group_work_manager` runs before the command's own `for update` on the same row, and a share→update upgrade inside one transaction ABBAs against any command holding a parent first. Restated in §10 by T23.
- **Gates:** only the Wave 2 kit (`require_group_work_manager`, `can_manage_group_work`, `group_role_of`, `actor_level`) plus the new Manager tier `private.require_group_manager(p_group_id) returns uuid` = `require_group_work_manager` then, below level 6, `is_group_manager`; every branch raises `42501 group_manage_forbidden` (non-disclosing). Never `groups.category`.
- **Shape:** `public.<verb>_<noun>()` `security invoker` → `private.*_impl` `security definer set search_path = ''`; four-role revoke + explicit grant; full-state replace for `update_*` (OD5); notifications through `private.notify` with `p_link`; every new `private` function is a categorised `tracker_grants` row; mutation table in every report; harness validated on a known-failing mutant, psql `-q -t -A`; `dblink` assertions proved on committed state or by reading.
- **Operational rule for T12/T13:** the implementer re-runs `git grep -ln "add_independent_team_member\|add_department_team_member\|add_project_member\|grant_project_responsible\|create_project\|archive_project" supabase/tests scripts` when the branch is cut, and the count goes in the PR body — dobre's stack tests insert legacy roster rows and rely on the mirror.
