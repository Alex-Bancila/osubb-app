# Production readiness — grill rulings (2026-09-23)

> Rulings from the grilling of 2026-09-23 on the per-page changes, the remaining waves, and the issue
> graph that takes the app to production. Issues, labels, and milestones are applied to GitHub only after
> Alex's go-ahead. Glossary changes land in `CONTEXT.md` as each term is resolved.

## Facts established before the rulings

- Event creation from the agenda is on `main` (#661, 2026-09-23). The Application commands are on `main`
  (#584, 2026-09-23); their UI is #589, open. Hiding the Request form from BCE+ is #631, filed.
- `express_task_interest_impl` makes the first eligible Member the Executor (`first_come`), later Members
  queue; `give_up_task` and `update_task` promote the oldest pending Candidate automatically.
- `announcement_reads` exists (self-only policy); read state does not affect order; the unread count is on
  the page header only. Announcements are still written directly under `auth_level() >= 4` (#581 open).
- Notifications: "Marchează tot ca citit" is a direct update at `NotificationsScreen.tsx:126-133`.
- Acasă: greeting, `MyPointsCard`, and for `seeLeadership` the Leaderboard and Cup cards. No tasks/events.
- Taskuri: member tabs use `TaskCard` (one column); manager tabs use a 7-column horizontally scrolling table
  with Origine / Stare / Campanie / title search. Disponibile already shows org-audience Opportunities of
  other Groups, sorted own Groups first, without a visual distinction.
- `tasks.description` is plain text; `submit_task_for_review(p_task_id)` takes no note; no markdown or
  link handling anywhere; no validation library; no date-range filter anywhere.
- `profiles` has no nickname column; `MemberProfileDialog` exists and is used in two places; names are
  otherwise plain strings or private one-off components.
- Voluntari shows up to three Group chips + "+N"; Profil edits `full_name`, `phone`, `avatar_color` directly.
- Calendar is an agenda list, upcoming only, no month grid, no filters.
- Milestones already exist per wave (Wave 1–4) plus eleven old Epic milestones with stragglers.
